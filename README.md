# ORION-Rover - Groupe 2

Robot livreur autonome intelligent - ORION UNIVERSITY
Atelier pilote TECH V2 - Novembre 2026

## Objectif
Developper un robot autonome capable de suivre une ligne, eviter les obstacles, reconnaitre les panneaux et effectuer des livraisons.

## Architecture
- firmware : controle ESP32, capteurs et moteurs.
- backend : serveur Python et API Flask.
- frontend : interface web HTML, CSS et JavaScript.
- ai : vision artificielle et classification des panneaux.
- docs : documentation technique.
- tests : validation du systeme.

## Technologies
ESP32, C++, PlatformIO, Python, Flask, OpenCV, TensorFlow, SQLite, Git et GitHub.

Groupe 2 - 5 etudiants.
